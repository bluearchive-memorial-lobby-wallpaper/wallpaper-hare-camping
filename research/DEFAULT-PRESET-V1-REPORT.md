# v1 默认参数与显示回归报告

> 日期：2026-08-11
> 版本：`1.0.0`
> 结论：默认参数已冻结，显示回归通过

## 1. 冻结参数

| 参数 | 默认值 |
| --- | ---: |
| 模型缩放 | `0.80` |
| 模型 X / Y | `0` / `0` |
| BGM 音量 | `50` |
| 对话音量 | `70` |
| 项目 FPS 上限 | `60` |
| 主题/清屏色 | `#0e4eac` |
| 默认画质 | 1080P 渲染 / 2K 纹理 / 60 FPS |

这些值同时写入运行时默认设置和 Wallpaper Engine `project.json`，
`test:settings` 与发行构建会校验两者一致性。FPS 实际上限取项目值与
Wallpaper Engine 全局值中的较低值；因此项目默认 `60` 不会绕过宿主更低的限制。

## 2. 测试环境与方法

- 主显示器：3840×2160 @ 160 Hz，16:9；
- 真实宿主：Wallpaper Engine 64 位网页壁纸宿主；
- 默认画质：1080P 内部渲染、2K 模型纹理；
- 每个宿主样本从新的临时项目路径启动，避免 WE 已保存的用户属性覆盖默认值；
- 相同比例的不同物理分辨率共享构图计算；`test:display` 直接调用生产布局函数校验精确内部画布和世界矩形。

## 3. 分辨率和宽高比结果

| 代表显示器 | 比例 | 默认内部画布 | WE 画面结果 |
| --- | ---: | ---: | --- |
| 1920×1080 / 2560×1440 / 3840×2160 | 16:9 | 1920×1080 | 无黑边、无拉伸，中心为 `0/0`；4K 全屏由项目所有者实测 |
| 1920×1200 / 2560×1600 | 16:10 | 1728×1080 | 无黑边、无拉伸，比 16:9 显示更多纵向内容 |
| 3440×1440 | 21:9 | 2580×1080 | 无黑边、无拉伸，按 cover 构图裁切上下内容 |
| 5120×1440 | 32:9 | 3840×1080 | 无黑边、无拉伸，上下裁切显著，但中心和人物比例正确 |
| 1024×768 | 4:3 | 1440×1080 | 无黑边、无拉伸，窄屏显示更多纵向内容 |

`0.74` 是项目所有者在 3840×2160 16:9 全屏下手动确认的完整内容边界；
本次冻结值 `0.80` 在全部宿主样本中都没有出现黑边。滑块的允许范围本次未改变，
以保留用户主动构图的自由；冻结只约束新项目的默认值。

## 4. 画质预设

| 属性页选项 | 渲染 | 纹理 | FPS 上限 |
| --- | ---: | ---: | ---: |
| 默认 | 1080P | 2K | 60 |
| 2K | 1440P | 4K | 60 |
| 4K | 2160P | 4K | 60 |
| 最高 | 2160P | 8K | 160 |

`Custom` 不是固定预设，用于显示并保留独立的渲染、纹理和 FPS 属性。
非自定义预设下三个子属性会隐藏，避免属性页显示值与实际生效值不一致。
真实 WE 宿主面板已分别确认默认预设为 `1080P · 2K texture · 60 FPS`，
最高预设为 `4K · 8K texture · 160 FPS`；两者均正常载入并保持响应。

## 5. 属性分组预设

属性页可见标签与选项全部保持英文且不带说明序号。`Position & Scale` 的
`Default` 固定为缩放 `0.80`、X/Y `0/0`；`Animation & Interactions` 的
`Default` 固定启用入场、交互、鼠标跟随、摸头和对话。两个分组切换到
`Custom` 时会显示并恢复各自此前保存的子属性。

`Dialogue Language` 的三个固定选项保持字幕开启：简体中文和日语使用对应字幕，
韩语因没有对应字幕回退到简体中文；`Custom` 才显示语音语言、字幕开关与字幕语言。
`BGM` 关闭时隐藏音量。`Debug` 提供 `Off`、`Debug Panel Only`、`All` 和
`Custom`，只有自定义模式才显示交互区域和调试面板子开关，面板开启后再显示面板语言。

## 6. FPS 和默认值回归

- `test:settings`：冻结默认值、全部分组预设、自定义值恢复、四个固定画质预设、WE 全局/项目 FPS 取低值和临时覆盖优先级通过；
- `test:fps`：15/30/60/160/无限制的帧数与动画时间累计通过；
- `test:display`：4:3、16:9、16:10、21:9 和 32:9 生产布局计算通过；
- `npm run build`：TypeScript、Vite 离线构建、项目元数据和冻结默认值校验通过。

## 7. 结论

`v1` 默认参数适用于已测的 4:3 至 32:9 视口。常见 16:9、16:10 和
21:9 可作为正常支持范围；32:9 因屏幕极宽会有明显上下裁切，属于预期的 cover 行为，不是黑边或拉伸缺陷。
